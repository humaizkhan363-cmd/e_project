BEFORE YOU SUBMIT
1. Fill in your name, enrollment no., batch / group, faculty, centre and submission date:
   - Project report: the cover page is a picture - print it and write on the lines, or type the
     details in a text box over the "Submitted by" panel in Word.
   - Nexus_Status_Report.xlsx and Nexus_Feedback_Form.xlsx: replace every [bracket] placeholder.
   - Presentation, slide 1: "Presented by".
2. The table of contents in the report already has page numbers (no F9 needed).
3. Make the database backup (required by the eProject readme):
   SSMS > right-click NexusServiceMarketingDb > Tasks > Back Up... > Full > Add path > OK  (creates a .bak file)
4. Put in ONE zip named like  Batch_Group_NexusServiceMarketingSystem.zip :
   - Source code folder
   - These documents
   - The .bak file
   - Database\NexusServiceMarketingDb-schema.sql (already inside the source)
Only ONE submission is allowed per group, so check everything first.

RUN THE PROJECT (details in README-RUN.md)
   SQL Server: Server name "."  -  SQL Server Authentication  -  sa / aptech
   dotnet ef database update      (creates the database and 19 tables)
   dotnet run                      then open http://localhost:5294 in Chrome   (admin / Admin@123)
